# saschalammers.github.io

Dieses Repo existiert nur, um eine `robots.txt` auf der Domain-Wurzel von
`saschalammers.github.io` bereitzustellen. Crawler lesen `robots.txt`
ausschliesslich unter `https://saschalammers.github.io/robots.txt` - eine
Datei in einem Projekt-Repo (z. B. `/artifacts/robots.txt`) wird ignoriert.

Die `robots.txt` sperrt die gesamte Domain fuer alle Bots und gilt damit
auch fuer `https://saschalammers.github.io/artifacts/`.
